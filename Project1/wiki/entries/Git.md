# Git

Git is a version control tool that can be used to keep track of versions of a software project.

## GitHub

GitHub is an online service for hosting git repositories.

### Github Repository

GitHub repository adalah tempat penyimpanan proyek yang memungkinkan Anda mengelola dan berbagi kode sumber bersama kolaborator. Sebuah repo dapat menyimpan kode, dokumentasi, gambar, atau file lain yang diperlukan untuk proyek Anda.
